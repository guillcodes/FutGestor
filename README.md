FutGestor
Sobre o projeto:
O FutGestor é um sistema de gerenciamento de campeonato de futebol desenvolvido em Java utilizando Programação Orientada a Objetos e arquitetura MVC.
O sistema permite cadastrar times, jogadores, técnicos e partidas, além de gerar a classificação do campeonato e listar os artilheiros.

-Funcionalidades

- Cadastro de times
- Cadastro de jogadores
- Cadastro de técnicos
- Associação de jogadores aos times
- Associação de técnicos aos times
- Cadastro de partidas
- Listagem de partidas
- Classificação do campeonato
- Salvamento dos dados em arquivos

-Estrutura do projeto

-Model
Contém as classes do sistema.

Exemplos:
- Pessoa
- Jogador
- Tecnico
- Time
- Partida
- Campeonato

-Controller
Contém as regras de negócio.

Exemplos:
- JogadorController
- TimeController
- PartidaController
- CampeonatoController

-View
Responsável pelos menus e interação com o usuário.

-Util
Classes auxiliares para salvar arquivos e registrar logs.
